# Underwater models

Local GLB assets used by the desktop underwater ambient scene.

The scene currently selects:
- `fish_animated.glb`
- `stylized_fish.glb`
- `clown_fish.glb`
- `tropical_alien_fish_animated.glb`
- `cartoon_shark_animated.glb` (two route/size presets)
- `colorful_jellyfish.glb`
- `exotic_blue_jellyfish.glb`

Other uploaded models stay available for later visual tuning but are not loaded by the browser.

Keep license/source information for every third-party model alongside the repository/project records before production distribution.
